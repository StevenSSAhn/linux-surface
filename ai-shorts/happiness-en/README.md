# "Happiness Is the Absence of Pain" — English AI Remake

An English-language recreation of a 59-second Korean YouTube Short
(`youtube.com/shorts/6FxfsPN0uss`), rebuilt shot-for-shot with AI generation.

## What's here

| File | Purpose |
|---|---|
| `source-analysis.md` | Scene-by-scene breakdown of the original (14 scenes, timings, shots, visuals) |
| `script-en.md` | The English production pack: narration, image prompts, motion prompts, per scene |
| `subtitles.srt` | Burn-in / upload-ready captions, timed to the shot list |
| `production-runbook.md` | Exact tool sequence to actually generate it |

## Approach

**Structure is copied, wording is not.** The original's 14-beat arc, shot types,
casting, palette and timing are reproduced faithfully — that's the "그대로 모방"
part. The narration is rewritten in original English rather than translated
line-by-line, because the source VO is a specific writer's phrasing. The ideas
underneath (Gracián / Schopenhauer on happiness as negation) are public domain.

**Format:** 9:16 vertical, 59s, 14 cuts, photoreal cinematic, single male
narrator, no on-camera speaker.
