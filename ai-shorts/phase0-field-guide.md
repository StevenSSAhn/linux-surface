# Phase 0 — 직접 관찰 가이드

에이전트가 못 하는 부분입니다. 이 환경에서는 YouTube 접근이 정책으로 막혀
있어, **경쟁 채널을 실제로 보고 댓글을 읽는 일은 사람만 할 수 있습니다.**
2차 조사(패턴·사례·스타일 레퍼런스)는 에이전트가 병렬로 진행 중입니다.

목표는 20개 채널을 "구경"하는 게 아니라 **게이트 0을 통과할 한 문장**을
얻는 것입니다:

> "___를 위한 ___ 채널, 남들과 다른 점은 ___"

---

## 준비

- **로그아웃 상태 또는 시크릿 창**에서 보세요. 로그인 상태면 추천 알고리즘이
  이미 본인 취향에 맞춰져 있어서 시장을 못 봅니다
- 가능하면 **VPN으로 미국**에 붙으세요. 타겟이 영어권이면 영어권 피드를
  봐야 합니다. 한국 IP의 영어 콘텐츠 피드는 다릅니다
- 아래 표를 스프레드시트로 옮겨서 채우세요

---

## 관찰 1 — 채널 해부 (12~20개)

검색어 예시: `stoic shorts`, `philosophy shorts`, `daily wisdom`,
`eastern philosophy`, `zhuangzi`, `schopenhauer`, `korean philosophy`,
`ancient wisdom animated`

**애니메이션/일러스트 룩 채널을 우선**으로 잡으세요. 포맷을 그쪽으로
정했으니 실사 채널은 대조군으로 3~4개면 충분합니다.

| 항목 | 기록할 것 |
|---|---|
| 채널명 / 구독자 | |
| 룩 | 어떤 스타일인지 한 줄 (플랫 벡터 / 실루엣 / 유화풍 / 수묵 / 타이포) |
| 첫 3초 | **오프닝 문장을 그대로 받아쓰기.** 이게 가장 중요한 데이터입니다 |
| 첫 프레임 | 무엇이 화면에 있나. 얼굴? 텍스트? 추상? |
| 음성 | 사람인가 AI인가. 남/여. 톤 |
| 자막 | 있나. 스타일 |
| 길이 | 초 |
| 업로드 빈도 | 주 몇 편 |
| 조회수 분포 | **최고 / 중앙값 / 최저.** 평균 말고 분포 |
| 다루는 인물·텍스트 | |

**조회수 분포를 꼭 보세요.** 채널 전체가 고르게 10만이면 안정적인
포맷이고, 한 편만 500만이고 나머지가 3천이면 그건 운이 한 번 터진 것뿐
입니다. 후자를 모델로 삼으면 안 됩니다.

---

## 관찰 2 — 훅 받아쓰기 (30~50개)

**이게 Phase 0에서 가장 값진 산출물입니다.** 채널 단위가 아니라 영상 단위로,
잘 된 영상의 **첫 문장만** 모으세요. 조회수와 함께.

```
[조회수] | [첫 문장 그대로] | [유형]
```

받아쓰기가 30개쯤 쌓이면 유형이 저절로 보입니다. 분류 예시:

- **주장 선언** — "Happiness is not the goal."
- **2인칭 지목** — "You're not tired. You're uninspired."
- **역설/반전** — "The more you want it, the less you'll get it."
- **질문** — "Why do rich people look so unhappy?"
- **인물 도입** — "This man gave up an empire to sweep floors."
- **완만한 도입 (slow build)** — "Everyone wants to be happy…"

마지막 유형이 몇 개나 나오는지 세어보세요. **거의 없을 겁니다.** 그게 우리
원본이 영어권 기준으로 훅이 약하다는 판단의 실증이 됩니다. 만약 많이
나온다면 제 판단이 틀린 것이니 그대로 알려주세요 — 계획을 고칩니다.

---

## 관찰 3 — 댓글 정독 (채널 5~6개)

베스트 댓글만 읽지 마세요. **부정적인 댓글과 논쟁이 붙은 스레드**를 찾으세요.
사람들이 뭘 좋아하는지보다 **뭘 지겨워하는지**가 훨씬 유용합니다.

찾을 신호:

- "AI voice" 지적 — 몇 %나 알아채는지, 알아채면 화를 내는지 그냥 넘어가는지
- "이 인용 출처 틀렸다" — 오귀속은 이 니치에서 신뢰를 즉사시킵니다
- "또 마르쿠스 아우렐리우스냐" 류의 피로감
- "bro stoicism" / 자기계발 팔이라는 비판
- 반대로 **긍정 댓글이 구체적으로 뭘 칭찬하는지** — 목소리? 그림? 문장?

각 신호를 실제 댓글 문장 그대로 3~5개씩 모아두세요.

---

## 관찰 4 — 니치 공백 확인

에이전트가 2차 조사로 후보 축을 좁혀 올 겁니다. 그 결과가 나오면, 지목된
키워드를 **직접 검색해서 실제로 비어 있는지** 확인해 주세요.

확인 방법: 검색했을 때 (a) 결과가 적은가, (b) 결과가 있어도 조회수가 낮은가,
(c) 있는 것들의 품질이 낮은가. 셋 다면 진짜 공백입니다. **(a)만 해당하면
수요 자체가 없는 것일 수도 있으니 주의하세요** — 아무도 안 만드는 데는
이유가 있는 경우가 많습니다.

## 게이트 0 판정

위 넷을 마치면 아래를 채울 수 있어야 합니다. 못 채우면 제작으로 넘어가지
않습니다.

- [ ] 채널 한 문장 정의 — "___를 위한 ___ 채널, 다른 점은 ___"
- [ ] 채택할 훅 유형 3가지 (Phase 1에서 A/B 할 것)
- [ ] 목표 룩 1가지 + 레퍼런스 이미지 5~10장
- [ ] 피해야 할 것 목록 (관찰 3에서 나온 실제 불만)
- [ ] 다룰 텍스트/인물 후보 10개 — 최소 3편 분량의 소재가 확보된 것으로

마지막 항목이 함정입니다. 소재가 3편에서 마르는 축을 고르면 Phase 2에서
막힙니다. **10개 후보를 못 채우면 축을 다시 고르세요.**
